# Landing Figma (Demo)

Адаптивный одностраничный лендинг, сверстанный на чистом HTML и CSS.

## 🚀 Демо
Посмотреть сайт вживую можно здесь:
👉 [https://redsea1970.github.io/landing-figma/](https://redsea1970.github.io/landing-figma/)

## 🛠 Технологии
- HTML5 (семантическая верстка)
- CSS3 (Flexbox, CSS Grid, CSS-переменные, адаптивность)
- GitHub Pages (хостинг)

## 📂 Структура проекта
- `index.html` — основная разметка страницы.
- `style.css` — стили (темная тема, сетка, анимации).
- `.nojekyll` — файл для корректной работы GitHub Pages.
